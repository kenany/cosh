# cosh

Calculate the hyperbolic cosine of a number.

## Example

``` javascript
import { cosh } from 'cosh';

cosh(1);
// => 1.5430806348152437
```

## Installation

``` bash
$ npm install cosh
```

## API

``` javascript
import { cosh } from 'cosh';
```

### `cosh(x)`

Given a _Number_ `x`, returns the hyperbolic cosine of `x` as a _Number_.
